# W3 手算记录（D1）

> 计划书 A1 要求：手算三问，**不开电脑**。本文件记录作答与判分，A2 之后回填程序验证结果。

## 题目

点 `p = (1, 0)`：先绕原点**逆时针转 90°**，再**沿 x 方向平移 1 米**。

换算规则（可抄）：
- 逆时针 90°：`(x, y) → (−y, x)`
- 平移 `(1, 0)`：`(x, y) → (x+1, y)`（"+x 方向"，见下方勘误）

---

## 标准答案

| 步骤 | 坐标 | 说明 |
|---|---|---|
| 起点 | **(1, 0)** | |
| ① 先转 90° | **(0, 1)** | x 轴上的点转到 y 轴 |
| ② 再平移 (1,0) | **(1, 1)** | 平移在旋转**之后**，不被旋转影响 |
| ③ **反序**：先平移 (1,0) | **(2, 0)** | |
| ④ 再转 90° | **(0, 2)** | 平移在旋转**之前**，被一起转了 90° |

**② = (1,1) ≠ ④ = (0,2)** → 变换不可交换。

---

## 我的实际作答（原始记录）

```
起点 (1,0)  ✓
转完 (0,1)  ✓
平移之后 (1,1) 或 (-1,1)      ← 对（+x 那支对，−x 是多余分支）
反序先平移 (0,0) 或 (2,0)     ← 对（+x 那支 (2,0) 对）
反序转完 (1,1) 或 (-1,1)      ✗ 错
```

### 扣分点 1：最后一行算错（严重）

**反序转完应该是 (0, 2)，不是 (1, 1)。**

自相矛盾的地方：嘴上说"不一样"，但填的两行数字 ② 和 ④ **是同一个 (1,1)** —— 数字在说"一样"。
说明第 ④ 行**没有真的算**，是把上一行的答案抄下来了。

**这恰恰是 A1 要抓的东西**：不是"知不知道不可交换"这个结论，
是"有没有真的把反序那两步走完"。结论背得下来，数字没走完。

### 扣分点 2：`±x` 两个分支都写了（次要）

"沿 x 方向"按 A2 的矩阵 `T = [[0,-1,1],[1,0,0],[0,0,1]]` 取 **+x**（右上角那个 `1` 就是 `t_x`）。
写两个分支本身不算错，但说明**没先定死符号就开算** —— 本周后面所有"方向"问题都是这个毛病的放大版。

## 那句"人话"（A1 真正的考点）

> **平移放在旋转「之前」，它会被旋转一起转走；放在「之后」，它是原封不动的。**

- 正序 `T_trans · R`：点先被 R 转成 (0,1)，**再**加 (1,0) —— 这个 (1,0) 是在**原坐标系**里加的，朝 +x，没被转。
- 反序 `R · T_trans`：点先变成 (2,0)，**再**被 R 转 —— 连那个 +x 的 1 米一起转了 90°，变成朝 **+y**：(0,2)。

写成矩阵就是：**写在 R 右边的东西会被 R 转，写在 R 左边的东西不会。**

这条和下周 D2 的"下标相邻消去" `T_base_cam @ T_cam_obj` 是同一件事：
**位置决定命运，不是符号本身。** 同一个 `t`，放左放右结果完全不同。

### 最有信息量的一行

两个顺序的矩阵，旋转块完全相同，**只有平移量那个 `1` 换了槽位**：

```
T_pos = [[0, -1, 1],      ← 1 在 [0][2]，x 分量
         [1,  0, 0],
         [0,  0, 1]]

T_neg = [[0, -1, 0],      ← 1 在 [1][2]，y 分量
         [1,  0, 1],
         [0,  0, 1]]
```

**同一个"1 米"，从 x 槽跑到 y 槽。** 这就是"写在 R 右边的会被转，写在左边的不会"的字面证据。

## D1 复盘

### L1 几何层

- **变换不可交换**，原因是**位置**不是符号：`T_trans · R` 里的平移在原坐标系里加（朝 +x）；`R · T_trans` 里的平移被 R 一起转了 90°（朝 +y）。
- 记忆句：**写在 R 右边的东西会被 R 转，写在左边的东西不会。**

### L2 工程层

- `np.cos(np.pi/2) = 6.12e-17`，**不是 0**。所以本周所有比较一律 `np.allclose`，不用 `==`。
- `det(R) = +1` 才是旋转；`det(R) = −1` 是**镜像** —— 说明某处符号错了，或用了行向量约定。
- 正交性 `RᵀR = I` 是"矩阵写对了"的自检，和 det 一起用。

### L3 方法论层（本次最大的收获）

**"知道结论" ≠ "算过过程"。**

我的实际失误：嘴上说"不一样"，但手算那两行数字都填了 (1,1) —— **结论和数字自相矛盾**。
说明反序那一步没真的走完，是把上一行抄了下来。

> 这类错误的形状是：**结论对，过程没落地**。它在 A1 只是丢一个坐标，
> 到 D4 的 P4 算例（手算 = 程序）就会变成一个查不出来的方向错误。

### L4 待改的习惯

**方向先定死再开算。** A1 里我同时留了 `±x` 两个分支，本质是没定符号就开始算 ——
本周后面所有"方向搞反"的问题都是这个毛病的放大版。
