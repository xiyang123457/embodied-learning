## 一、`det(J)` 的闭式

把 `J` 的两列记作 `c1`、`c2`：

```
c1 = ( −l1 sinθ1 − l2 sin(θ1+θ2),  l1 cosθ1 + l2 cos(θ1+θ2) )   ＝ 末端坐标旋转 90°
c2 = ( −l2 sin(θ1+θ2),             l2 cos(θ1+θ2) )              ＝ (末端 − 肘) 旋转 90°
```

两列叉积（二维即 `c1x·c2y − c1y·c2x`）：

```
c1 × c2 = l1·l2·[ sin(θ1+θ2)cosθ1 − sinθ1·cos(θ1+θ2) ]
        = l1·l2·sin(θ2)
```

最后一步用了和角公式 `sin(A−B) = sinA cosB − cosA sinB`，其中 `A = θ1+θ2`、`B = θ1`。

**于是奇异条件一行写完：**

```
det(J) = 0  ⟺  sin(θ2) = 0  ⟺  θ2 = 0（伸直）或 θ2 = π（折叠）
```

这两个姿态 W3 都画过。当时它们只是「三个姿态里的两个极端」，现在它们有了名字：**工作空间边界**。

实测：`det_ana(1.2) = 0.932039`，`sin(1.2) = 0.932039`。

## 二、条件数：这个位形还能不能用

`cond(J)` = 最大奇异值 / 最小奇异值，含义是「输入误差被放大几倍」。

固定 `θ1 = 0`，让 `θ2` 从 π/2 逼近 0：

| `θ2` | `det(J)` | `cond(J)` | 判读 |
|---|---|---|---|
| π/2 = 1.571 | 1.000 | **2.62** | 放心用 |
| 0.1 | 9.98e-02 | **50.0** | 注意 |
| 0.01 | 1.00e-02 | **500** | 基本不能信 |
| 1e-4 | 1.00e-04 | **5.0e4** | 不可用 |
| 0 | 0 | **inf** | 奇异 |

**规律：`cond ≈ 5/θ2`。** `θ2` 缩小 10 倍，条件数涨 10 倍。

> 计划书 B2 的表在 `θ2 = 1e-4` 一格写 2.2e5，本机实测 5.0e4。
> 计划书前四格（2.6 / 50 / 500）都符合 `5/θ2`，按同一规律 `1e-4` 应为 5e4，那一格应是笔误。
> 本笔记采用实测值。

经验线：`cond < 10` 放心用；10–100 注意；`> 1000` 不能信。

## 三、速度级逆解：让数字爆掉

给定末端速度 `ẋ`，关节速度是 `q̇ = J⁻¹ ẋ`。

设定 `θ1 = 0`，让末端以 **1 m/s 沿 +x**（也就是沿手臂方向）移动：

| `θ2` | `|q̇|`（rad/s） | 折合圈/秒 | 能不能执行 |
|---|---|---|---|
| π/2 | **1.0** | 0.16 | 正常 |
| 0.1 | **22.3** | 3.5 | 偏快 |
| 0.01 | **223** | 35 | 做不到 |
| 1e-4 | **22361** | 3559 | 荒谬 |

解析式：`|q̇| = √5 / θ2`（`θ1 = 0`、`l1 = l2 = 1` 时）。

**为什么：** `J⁻¹ = adj(J)/det(J)`。`det → 0` 时分母没了。数学上没问题，物理上关节转不了那么快。

`W4_D2_2_ik_blowup.png` 上那条 10 rad/s 的虚线就是分界：**`θ2 < 0.2236` 之后，数学解存在，物理上做不到。**

> **一句话：奇异不是数学问题，是物理问题。**
> 数学告诉你需要 22361 rad/s，物理告诉你电机最多 10 rad/s。

## 四、阻尼最小二乘：只到「知道它解决什么」

```
q̇ = Jᵀ (J Jᵀ + λ² I)⁻¹ ẋ        λ = 0.1
```

| `θ2` | 无阻尼 `|q̇|` | 阻尼后 `|q̇|` | 末端实际速度 | 跟踪误差 |
|---|---|---|---|---|
| π/2 | 1.0 | 0.98 | (0.990, −0.010) | 0.014 |
| 0.1 | 22.3 | 3.72 | (0.170, −0.050) | 0.832 |
| 0.01 | 223.6 | 0.446 | (0.002, −0.006) | 0.998 |
| 1e-4 | 22361 | 0.0045 | (0.000, −0.000) | **1.000** |

看清代价：`θ2 = 1e-4` 时关节速度从 22361 压到 0.0045（压了 500 万倍），**但末端一步没动，跟踪误差 1.0**。

> **阻尼不是「修好了」，是「用精度换稳定」。**

这句话在 VLA / Sim-to-Real 论文里会反复出现。本周不实现，只记住这个取舍。

## 五、三个要记住的数字

1. `det(J) = l1·l2·sin(θ2)`，奇异在 `θ2 = 0` 和 `θ2 = π`
2. `cond ≈ 5/θ2`，`θ2 = 0.01` 时已经是 500
3. `|q̇| = √5/θ2`，`θ2 = 1e-4` 时要 22361 rad/s
