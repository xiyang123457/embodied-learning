第 01 讲 · 约 30–45 分钟
一次网格之旅：我们到底在评价什么？

1. 先走一趟

想象你在一个铺着冰的房间找出口。你告诉小车“往下”，但冰面可能让它滑向旁边。到出口得 1 分，其他时候得 0 分；掉进洞或到出口就结束。你希望它以后越走越好。

S····H·H···HH··G

这是你仓库 src/mdp_gridworld.py 中的环境。状态是格子编号；动作有左、下、右、上；一局从重置开始，到任务终止或人为时间上限结束。滑面只决定执行后会去哪里，不改变你发出的动作。

2. 一次得分，不等于这一路的成绩

奖励是环境每一步给的分；回报把从当前起的奖励合起来。你可能觉得“只要最终都得 1 分，早到晚到没有区别”，但我们有时希望更早到。因此给晚一点的奖励打折。

具体数字。假设从现在起依次得到 0、0、1，折扣系数为 0.9。那么第一步奖励照算，第二步乘 0.9，第三步再乘一次 0.9。总回报是 0 + 0 + 0.81 = 0.81。如果第一步就到终点，回报是 1。

写成公式，读作“当前回报等于这一步的奖励，加上打折后的下一步奖励，再加更远的奖励”。

查看可复制的 LaTeX 源码G_t = r_t + \gamma r_{t+1} + \gamma^{2}r_{t+2}+\cdots

这里下标 t 是当前环境步数；r 是奖励；G 是这一次经历得到的回报；γ 是折扣系数。你不必背公式，先记住：奖励是一格，回报是一段路。

3. 一次旅程与长期平均

同一个格子里选择同一个动作，在滑面上可能滑去不同地方；每次旅程的回报可能不同。为了决定之后怎么走，我们关心长期平均，而不是一局的偶然结果。

假设按某个走法反复从 A 出发：一半时候回报 1，一半时候回报 0，那么平均回报是 0.5。状态价值 V 就是固定一种策略，从某格出发后的平均回报。动作价值 Q 则是先指定一个动作，之后再按同一策略走的平均回报。

问题回答它的量例子
这一步得了几分？奖励进入终点得 1
这趟经历总共得多少折扣分？一次回报三步奖励 0、0、1，回报 0.81
反复从 A 出发，平均如何？状态价值 V假设平均 0.5
先从 A 向下，平均如何？动作价值 Q假设平均 0.7

价值是数学上的期望；你训练出的 Q 表或神经网络只是对它的估计。一次采样回报也不是精确价值。

容易误会：价值 0.95 就是成功率 95%。
反例：你的不滑网格最短 6 步到终点，折扣系数 0.99 时起点价值约 0.951，但这个确定性策略可以 100% 成功。价值包含奖励何时得到，成功率只数在规定步数内成功的次数。

串起来：从网格出发，收集奖励形成回报；反复经历的平均回报是价值。接下来我们要决定：到底用什么规则选择动作？

先自己回答，再展开答案

① 奖励依次为 0、1，γ=0.9，回报是多少？② 如果从某格向下有时成功、有时掉洞，为什么一次回报不能代表 Q 的精确值？③ 价值和成功率为何可能不同？

答案：① 0.9，因为第二步奖励要打一次折。② Q 是反复经历的期望，一次只是一种可能结果。③ 价值还考虑奖励的大小和时机，成功率只统计是否在限定步数内成功。

第 02 讲 · 约 45–70 分钟
怎样让小车改变选择？

1. 先给每个方向一张抽签卡

在起点，小车可以左、下、右、上。假设现在它的抽签规则是：左 10%、下 40%、右 30%、上 20%。四个百分比加起来是 100%。这就是一个随机策略：它告诉我们在这个状态下各动作有多容易被抽到。

策略不是一次具体动作：抽签规则是“下 40%”；某一次抽出来的动作可能是“右”。不同位置可以有不同规则。记号 π(a|s) 读作“在状态 s 下选择动作 a 的概率”。

连接你的 Q-learning。你的代码先给每个状态的每个动作存一个 Q 值；评估时用 argmax 选分最高的动作。随机策略的另一种做法是直接学习抽签概率。在离散网格中两者都能用；后面连续机械臂动作会让直接输出分布更有用。

2. 一次行动好不好，要有比较对象

假设从当前格出发，依照现有策略，长期平均回报是 0.5。现在我们另外考察“第一步向下”：假设先向下以后，长期平均回报是 0.8。这个选择相对平常水平好多少？0.8 − 0.5 = +0.3。

这个差值叫优势（advantage）。它不是“这一次得了多少分”，而是“这个动作的预期结果与同一状态下基准水平的差”。

查看可复制的 LaTeX 源码A^{\pi}(s,a)=Q^{\pi}(s,a)-V^{\pi}(s)

公式中 Q 是“先选该动作”的期望回报，V 是“按现有策略从该状态出发”的期望回报；上标 π 提醒我们二者使用同一策略。若 Q=0.2，V=0.5，优势就是 −0.3：动作相对较差，即使它的回报仍是正数。实际训练时不知道精确 Q 和 V，使用从数据和价值网络得到的估计。

3. 用好坏调整抽签规则

如果某个被采样的动作估计优势为正，我们希望它在类似状态下更容易被选择；如果优势为负，希望它更不容易被选择。这就是策略梯度的核心直觉。它是对许多样本平均后调整网络参数，并不保证每一次小更新或每个状态都变好。

想象老师不会只说“得了 80 分”，而是说“你比自己以往平均高了 10 分”。价值估计 V 就像比较用的基准，称为 baseline。类比的边界是：V 是模型估出来的，可能不准；一个动作的好坏也要靠长期结果和多次采样判断。

4. Actor 和 Critic 分别干什么？

Actor：产生选动作的规则→ 环境：执行并给奖励→ Critic：估计状态价值→ 算优势，更新 Actor

Actor（行动者）是策略网络；Critic（评价者）通常输出状态价值估计。它们可以分开，也可以共享部分网络。价值网络不是给机器人下命令的控制器；它的评价帮助策略学习。

5. 看懂第一段代码：记录动作的可能程度

下面四个数字是策略网络对四个方向给出的未归一化分数（logits），代码将它们变成分布并抽一次。[1, 4] 表示 1 个状态、4 个方向；每次运行结果可能不同。

import torch
from torch.distributions import Categorical

logits = torch.tensor([[0.0, 1.0, 0.5, -0.5]])  # [1, 4]，教学示例
dist = Categorical(logits=logits)                 # 构造离散分布
action = dist.sample()                            # [1]，采样一个方向编号
logp = dist.log_prob(action)                      # [1]，该方向概率的对数
print(dist.probs, action, logp)

这里 dist 是抽签规则；action 是一次抽中的签；logp 是该次动作概率取自然对数后的值。上例只展示采样，没有进行参数更新。

6. 为什么要用对数？

先把 log 当成一个有用的“刻度”：概率 1 的自然对数为 0，概率 0.5 的自然对数约为 −0.693，概率越小对数越负。对数把多步概率相乘变成相加，计算梯度也方便。

在最简单的策略梯度中，可以把每个采样动作的 log 概率乘以它的优势，然后希望平均结果变大。框架通常做的是最小化损失，所以代码在前面加负号。优势视为固定的评价，不让策略损失通过它反向改变评价网络。

查看可复制的 LaTeX 源码L_{\mathrm{policy}}=-\mathbb{E}[\log\pi_{\theta}(a\mid s)\,\hat{A}]

其中 log π 是采样动作的对数概率，Â 是估计的优势，平均是对样本求平均。优势正时，增大目标会倾向提高该动作概率；优势负时会倾向降低它。这里讲方向，不承诺每个样本的概率在共享网络更新后一定单独按该方向变化。

# logp 和 advantage 均为 [B]，B 是样本数
# 教学片段：optimizer 已连接策略网络参数
loss = -(logp * advantage.detach()).mean()
optimizer.zero_grad()
loss.backward()
optimizer.step()

串起来：小车有一套抽签规则；用优势判断某个方向比平时好多少；用损失调整产生抽签规则的网络。

练习：说出来比记住名词更重要

① “下的概率 40%”和“一次抽到下”分别是什么？② V=0.5、Q=0.8，优势是多少？③ 训练中为什么策略损失前面有负号？

答案：① 前者是策略分布，后者是一次采样动作。② +0.3，表示向下的期望回报比基准高。③ 我们想让优势加权目标变大，优化器却做损失下降，所以最小化它的相反数。

第 03 讲 · 约 50–75 分钟
从四个方向到连续动作

1. 为什么四张卡不够了？

网格里动作只有四个编号。但机械臂沿 x 方向的控制量可以是 0.1、0.11、0.111……不是有限几个选项。W5 的 FetchReach 接口是四维动作，其中前三维表示末端目标位移比例；这里先只看一个维度，让问题简单一些。我们会先假设动作可以取任意实数，之后再讨论真实设备的动作范围。

2. 策略不直接给一个数，而是给一条分布曲线

假设网络输出两个数：均值 μ=0.2 和标准差 σ=0.1。它们共同确定一个高斯分布（也叫正态分布），从分布中可以抽取一个具体动作，比如 0.18。再次抽样可能得到 0.25。

  • 均值 μ：曲线中心在哪里。在这个例子里，动作往 0.2 附近集中。
  • 标准差 σ：分布有多散。σ 较大时样本更分散，较小时更多落在中心附近。
  • 采样动作：某一次真正抽出的数；它不等于整个分布，也不一定正好等于均值。
动手看：高斯分布的教学示意

横轴：连续动作值；纵轴：概率密度。蓝色面积表示动作落在 −0.2 到 0.2 的概率。调整均值和标准差，观察曲线与面积如何变化。

面积由数值近似计算，曲线在显示范围外的尾部未画出；图只解释分布，不代表机器人实验结果。

把均值右移，分布中心也右移；增大标准差，曲线变宽变矮、动作更分散。蓝色部分的面积才是落进该范围的概率。一次抽样会得到一个动作；改变分布后再次抽样，得到的动作不保证每次都朝同一方向变化。

3. 曲线高度和概率不是一回事

离散情况下，“选下”是一个独立选项，可以说它的概率是 40%。连续数轴上，相邻两个数之间总还能再细分。对理想连续分布，抽到恰好某一个精确值的概率为 0；我们用区间下面积谈概率，比如动作在 0.1 到 0.2 之间的概率。

曲线在某一点的高度叫概率密度。密度说明附近有多集中；密度乘以非常窄的区间宽度，可以近似该小区间的概率。密度不像概率那样必须不超过 1：例如标准差 0.1 的高斯分布在均值处密度约为 3.99；高度超过 1 没问题，因为整个曲线下的面积仍是 1。

容易误会：某点的密度为 3.99，就有 399% 的概率抽到该动作。
正确：3.99 是曲线高度，不是概率。区间概率是面积；某个精确点没有宽度，所以它的概率是 0。

4. 连续动作的 log_prob 到底是什么？

在 PyTorch 的 Normal 分布里，log_prob(action) 返回该动作位置的对数密度。密度为 0.5 时，对数约 −0.693；密度为 3.99 时，对数约 +1.38。它不一定是负数，也不能直接理解成“概率的对数”。

import torch
from torch.distributions import Normal

mu = torch.tensor([0.2])          # [1]，均值；实际由策略网络产生
sigma = torch.tensor([0.1])       # [1]，标准差，必须大于 0
dist = Normal(mu, sigma)
action = dist.sample()            # [1]，抽到一个实际动作
log_density = dist.log_prob(action)  # [1]，该动作位置的对数密度

机器人动作是多维时，每维都有值，代码常把各维 log density 相加，得到该动作向量的联合 log density。对有动作上下限的环境，需要正确处理分布变换及其对 log density 的修正；直接裁剪高斯样本，再按原高斯分布给裁剪结果计分，会改变概率关系。

串起来：网络输出分布参数，分布生成一次动作；曲线下的区间面积是概率，曲线高度是密度；连续 log_prob 是对数密度。

练习：判断并解释

① 把均值从 0 移到 0.5，曲线如何变化？② 固定均值，把标准差变大，曲线通常如何变化？③ 对连续动作来说，密度大于 1 是不是错误？④ 对数密度一定是负数吗？

答案：① 整条分布向右移动。② 更分散、峰值更低。③ 不一定，概率由面积决定，密度是高度。④ 不一定，密度大于 1 时自然对数为正。

第 04 讲 · 建议分两次读，约 90–130 分钟
先跟着小车走一遍，再看 PPO 的公式

这一讲解决的问题

你可能会问：“比例是什么？为什么要裁剪？负数时为什么还取小的？不是应该往中间靠吗？”我们只看一个格子、一个已经发生的动作，直到把四个问题说清楚。

1. 先别看公式：小车刚刚做了什么？

小车现在在起点。它要从“左、下、右、上”中选一个动作。假设这时它的旧策略是：下 40%，其他方向加起来 60%。你可以把它想成一个装有 100 张纸签的盒子：其中 40 张写“下”。

小车抽到“下”，随后继续往前走，最后抵达终点。我们把这次经历记下来。为聚焦一个问题，这里假设经过后面一讲的计算，我们得出：这次“下”相对于预期好 0.3 分。这个 0.3 就是优势的一个估计，记作 Â；它来自奖励和价值估计，第 05 讲会从头算出它。

现在，我们想修改抽签盒：既然这次的“下”看起来比预期好，是不是可以增加“下”的签？可以，但一条经历可能有偶然性，所以我们不想因为它就让策略一下子改得过于激进。

2. 概率比到底是比什么？

假设改了一点后，新的抽签盒里“下”的概率从 40% 变成 60%。我们把同一格、同一个动作的新概率除以旧概率：

查看可复制的 LaTeX 源码\rho=\frac{60\%}{40\%}=1.5

这里的 1.5 表示：新盒子里“下”的概率是旧盒子的 1.5 倍，也就是相对增加了 50%。它不表示概率变成 150%；新概率仍是 60%。如果新概率还是 40%，比例就是 1；若降到 20%，比例就是 0.5。

旧概率新概率新 ÷ 旧说人话
40%20%0.5选“下”的概率减半
40%40%1没有改变
40%60%1.5变成原来的 1.5 倍

这叫概率比率，论文常用 ρ 或 r 表示。它比较的是概率的变化，不是回报的比率，也不是动作大小。下面为了统一使用 ρ。原论文常用 rt 表示比例；不要与本讲义的奖励 r 混淆。连续动作时比较的是同一动作处的新旧概率密度，不是选中某个精确值的概率。

查看可复制的 LaTeX 源码\rho_t(\theta)=\frac{\pi_{\theta}(a_t\mid s_t)}{\pi_{\mathrm{old}}(a_t\mid s_t)}

公式里的分子是当前策略对这次动作给出的概率；分母是当时收集这次经历的旧策略给出的概率。两者必须对应相同状态与动作。代码里先保存旧的 log 概率，更新时计算新 log 概率；两者相减再取指数得到这个比。

3. 什么叫“目标”？为什么不是直接改概率？

先想成一张给优化器看的记分表。优化器会调整网络参数，试图让总体分数更大。对于刚才那条经历，我们最初给它的记分方式是：

查看可复制的 LaTeX 源码L_{\mathrm{raw}}=\rho_t\hat{A}_t

读成一句话：“概率比 × 这次动作的优势”。优势正，比例升高会让分数变大，所以优化器倾向增加这个动作的概率。优势负，比例降低会让分数变大，所以优化器倾向降低它。

注意：这里的分数不是环境奖励，也不是新的概率。它是为训练网络构造的目标值；最终的策略表现还要靠评估来判断。

先看看正优势。优势是 +0.3；比例从 1 变为 1.5。原来的分数是 1 × 0.3 = 0.3；新的分数是 1.5 × 0.3 = 0.45。按照这张表，继续提高比例会一直拿到更高分。问题是：我们只凭这批旧经历，未必应该奖励无限大的改变。

4. 裁剪目标是在做什么？

假设设定一个参考范围：0.8 到 1.2。PPO 会先拿实际概率比制作一个用于记分的副本：小于 0.8 就写成 0.8，大于 1.2 就写成 1.2，中间保持原样。这个动作叫 clip，中文常叫裁剪。

刚才实际比例是 1.5，副本就记为 1.2。于是我们得到两份分数：原始分数 1.5 × 0.3 = 0.45；裁剪分数 1.2 × 0.3 = 0.36。最后只把较小的 0.36 计入目标。

想象一条横向跑道：比例从 1 开始向右走。优势为正时，原始分数会一直增长；而比例超过 1.2 后，裁剪分数停在 0.36。取较小值之后，这个样本在 1.2 以外不再因为继续向右走而得到更高的记分。

这里没有把真实概率比强制拉回 1.2。裁剪的是计算分数时使用的副本。其他样本、共享网络参数及其他损失仍可能改变策略，所以实际比例仍可超过范围；它也不是严格的 KL 约束。

5. 最难的一步：优势是负数时，为什么还取较小值？

现在换一条同样在起点向下的经历：假设它的优势是 −0.3，意思是“这次结果比价值网络预期差 0.3”。我们希望降低这个动作的概率。假设旧概率仍是 40%，新概率降低到 20%，比例就是 0.5。裁剪副本是 0.8。

先把两份分数分别算出来，暂时不要想哪一个比例更接近中间：

计算哪份分数？计算结果
按实际比例算0.5 × (−0.3)−0.15
按裁剪比例算0.8 × (−0.3)−0.24

现在比较的是−0.15 和 −0.24 这两份分数，不是比较 0.5 和 0.8。数轴上 −0.24 更靠左，所以更小：最终计入 −0.24。

为什么不选更大的 −0.15？因为我们想让“把坏动作概率越降越低”获得的额外收益到此为止。如果取 −0.15，比例继续往 0 靠时，原始分数会从 −0.15 向 0 上升：由于训练目标要变大，优化器仍会因继续降低比例获得更高分。取 −0.24 后，只要实际比例在 0.8 以下，这个样本的目标就停在 −0.24，不再因为继续往下压比例而增加。

对照一下就清楚了：优势为正时，向上超过 1.2 后，分数停住；优势为负时，向下超过 0.8 后，分数停住。我们在两种情况下都对最终分数取较小值，才能把“向有利方向变化过多”的额外收益盖住。
“取小”说的是记分数值，既不是把概率本身取得越小越好，也不是直接要求概率比回到 1。

6. 如果策略朝错误方向变了呢？

比如一个好动作的优势是 +0.3，但它的概率比降到 0.5。这时原始分数是 0.15，裁剪分数是 0.24，取小值得 0.15。比例下降会让得分变差，优化器仍有动力纠正这个变化。反过来，坏动作的概率比升到 1.5 时也类似。

旧概率固定 40%，改变新概率和优势；裁剪范围固定为 0.8–1.2。这里每次只展示一个样本的教学计算。

7. 现在再看论文公式

论文用一个式子把上面的动作连起来：先算比例，得到原始分数与裁剪分数；取较小值；对采集到的各个样本求平均。

查看可复制的 LaTeX 源码L^{\mathrm{CLIP}}(\theta)=\mathbb{E}_t\left[\min\left(\rho_t(\theta)\hat A_t,\;\mathrm{clip}(\rho_t(\theta),1-\epsilon,1+\epsilon)\hat A_t\right)\right]

其中 E 是对样本求平均；Â 是提前估计的优势；ε 决定参考区间，比如 0.2 对应 0.8–1.2。clip 的输入是概率比，不是动作。目标要最大化；如果代码的优化器只会最小化，就把目标加负号变成 loss。

# 教学片段：ratio、advantage 各自是 [B]；B 是样本个数
original = ratio * advantage
clipped = ratio.clamp(0.8, 1.2) * advantage
objective = torch.minimum(original, clipped).mean()  # 越大越好
policy_loss = -objective                             # 最小化负数

这一讲串起来：旧策略抽出一次动作；优势告诉我们这次结果比预期好还是差；概率比衡量该动作的新旧可能程度；两种记分取较小值，避免这个样本对“有利方向的过大变化”继续给出额外奖励。

不看答案，试着自己说一遍

① 旧概率 40%、新概率 20%，概率比是 0.5；它表示什么？② 优势 −0.3、比例 0.5 时，比较的是哪两个数？为什么取 −0.24？③ 如果优势正但比例降到 0.5，取小值后还会鼓励比例继续降低吗？

答案：① 新概率是旧概率的一半。② 比较 −0.15 和 −0.24，选较小的 −0.24；继续降低比例不会使该样本的目标上升。③ 不会：原始分数降低，最大化目标会倾向纠正这个方向。它们都是单样本分析，不保证整体网络在每个状态的实际变化。

第 05 讲 · 建议分两次读，约 75–110 分钟
优势 A 是怎么计算出来的？

先回答最关键的一句：

优势要回答：“这次动作后的结果，比当时预计的结果好多少？”实际训练无法直接知道动作的真实长期平均效果，因此用回报、价值网络和轨迹数据估计它。下面先算一种最容易理解的估计，再看 PPO 常用的 GAE。

1. 还是刚才的小车：一次具体经历

回到第 04 讲。小车在起点 S 选“下”，到达中间格 B；下一步到达终点 G。为了容易手算，我们用一个简化示意，沿用 W7 的“到终点给 1 分，其余给 0 分”奖励，但这里的两步路线是教学示意，不是原 4×4 地图的最短路线。

起点 S→ 向下，奖励 0中间格 B→ 到终点，奖励 1G：真正终止

假设折扣系数 γ=0.9。先算从 S 做出“向下”以后，这一次实际经历的折扣回报：第一步得到 0；第二步得到 1，要乘一次 0.9；结果是 0.9。

2. 只看 0.9，还不能说比平时好多少

想象价值网络在出发前估计：“从 S 出发，按当前策略走下去，平均折扣回报大约是 0.6。”这就是价值估计 V(S)=0.6。它相当于一条基准线，是网络的预测，不是环境直接给出的标准答案。

把这次结果和基准比较：
这次轨迹的回报 0.9 − 出发前的估计 0.6 = +0.3。
所以我们可以把 +0.3 当作这一次“向下”动作的一个优势估计。它说明这次结果比预测高 0.3，并不保证“向下”的真实平均优势恰好为 0.3。

这就是上讲假设的 +0.3 从哪来。像这样用一次完整轨迹回报减掉基准，是一个容易理解的估计方法。一次成功可能是运气好，反复采样、共同训练有助于降低偶然性，但估计依然可能有误差。

查看可复制的 LaTeX 源码\hat A_t=G_t-V(s_t)

式中 G 是这次轨迹的折扣回报；V 是价值网络估计；上面的帽子表示“估计值”。G 减 V 和前面理论定义的 Q 减 V 有联系：如果第一步固定动作、以后按同一个策略反复走，回报的平均对应 Q；而一次回报只是一个样本。并不是先查出真实 Q，再直接拿到真实 A。

3. 价值网络说的 0.6 又是哪来的？

它不是人工提前告诉 PPO 的答案。Critic 是一个神经网络：输入状态 S，输出对未来回报的预测。开始时预测可能很不准；收集轨迹后，构造一个回报或价值目标，让网络通过回归损失逐步调整预测。

例如：它原来估计 0.6，训练目标假设是 0.9，价值损失会推动这个预测更接近 0.9。真实训练会用很多样本，目标可能还带有价值自举，也不会因为一次经历就立刻变为 0.9。Actor 决定怎么行动；Critic 估计未来回报；两者合作改进。

4. 为什么不总是等到最后再计算？

上面的小车两步就结束，很方便。假如机器人执行了几百步，或者数据采集到一半就停下来，我们可能暂时看不到完整回报。于是可以用价值网络对下一状态的预测，先估计后面可能得到多少。这叫自举：用还不完美的预测补上尚未观察到的未来。

沿用同一条 S → B → G 轨迹，假设 Critic 的旧预测是 V(S)=0.6、V(B)=0.7；到达真正终点后未来价值是 0。看看从 S 到 B 的这一步：

第 1 步，走到 B：
这一步奖励 0，加上下一格估值打折后的 0.9 × 0.7，共 0.63。
把 0.63 和出发前预测 0.6 比较：0.63 − 0.6 = +0.03。
这个差叫一步 TD 误差：刚刚看到的一步和对未来的新估计，让我们觉得比之前预想好 0.03。

TD 是 temporal difference（时间差分）的缩写。这个差也是估计线索，不是确定的最终优势。若价值网络预测不准，它也可能不准。

查看可复制的 LaTeX 源码\delta_t=r_t+\gamma V(s_{t+1})-V(s_t)

再看 B → G：这一动作得到奖励 1，G 是真正终点，所以未来价值是 0。第 2 步的 TD 误差为 1 + 0 − 0.7 = +0.3。

5. GAE：把两步的线索合起来

现在有两条线索：第 1 步误差 +0.03，第 2 步误差 +0.3。GAE 的想法是：算第 1 步的优势时，不只看眼前误差，也给后续误差一点权重。λ（lambda）控制让后续误差影响多大。

假设 γ=0.9、λ=0.8，第 2 步后真正终止，没有更多误差：

查看可复制的 LaTeX 源码\hat A_0=0.03+0.9\times0.8\times0.3=0.246

所以用 GAE 时，第 1 步得到的优势估计是 +0.246。它与“完整回报减基准”的 +0.3 不完全一样，因为两种估计使用信息的方式不同；GAE 在这里让后续误差额外乘了 λ。λ=0 时只用当前一步误差 +0.03；在这个完整回合示例中 λ=1 时会得到 +0.3。

一般公式只是把刚才的两步扩展到更多步：

查看可复制的 LaTeX 源码\hat A_t=\delta_t+\gamma\lambda\delta_{t+1}+(\gamma\lambda)^2\delta_{t+2}+\cdots

δ 是每一步的 TD 误差；γ 是折扣；λ 控制后续误差的权重；Â 是优势估计。通常 λ 较小时更依赖价值估计，λ 较大时纳入更多后续采样结果，往往能减少一部分偏差但增加方差。它不是保证更准的开关。

6. 真正结束、时间到了、数据收集暂时停了

这里要区分两个问题：是否用下一状态的价值补未来？是否把下一条误差接进当前回合？

情况未来价值自举GAE 是否接下一段
任务真正结束：到终点或掉洞不自举，未来价值为 0不跨回合
外部时间上限，任务本可继续从截断前的最终观测自举不接重置后新回合
采集批次结束，环境仍在继续从批次末的观测自举批次内没有后续误差，递推在边界停止

自动重置时，环境可能直接给出新回合的起点；要确认接口提供的最终观测，别拿新起点来估计上回合的未来。上述时间上限按外部截断处理；如果时间限制本身是任务定义的一部分，则须按该任务语义处理。

7. 把它放回 PPO 的更新循环

旧策略采样轨迹→ 价值网络估计各状态→ 算 TD 误差与 GAE 优势→ 用优势和概率比算 PPO 目标→ 更新网络，再采样

这一批数据更新时，旧 log 概率、优势和价值目标通常按本批计算结果固定。常见实现把“旧价值 + 未归一化的 GAE 优势”当作 Critic 的回归目标；策略损失使用的优势可能单独归一化，不能把归一化后的优势直接当作同一个价值目标。

# 单条转移的教学片段；数字是标量，非完整 PPO 程序
future = 0.0 if terminated else next_value  # 是否需要自举？
delta = reward + gamma * future - value     # 这一步的新线索
# GAE 的递推还要检查 truncated，避免接到重置后的新回合。

这一讲串起来：回报告诉我们这次经历的结果；Critic 给出出发前的预估；两者比较给出最直观的优势估计。GAE 用价值预测和多步 TD 误差形成另一种优势估计，再交给上一讲的 PPO 记分公式。

第 06 讲 · 约 75–110 分钟
扩散模型：为什么从噪声能生成东西？

1. 先看一个具体问题

这一次，我们想让模型做什么？

想象你有很多张杯子的照片，希望模型学会生成一张新的杯子照片。我们会先问三个问题：怎样制造训练题？网络的答案是什么？训练好以后怎样生成新照片？这三个问题先弄清楚，再看公式。

先暂时离开网格。你拿到许多清晰图片，想训练一个模型生成类似的新图片。直接让网络从随机数一下画出整张图很难。扩散模型采用另一种训练问题：我们自己加噪声，因为噪声是自己加的，所以知道监督目标是什么。

清晰样本→ 加一点噪声→ 加更多噪声→ 接近随机噪声

像一张照片被雪花干扰，越来越难看清。这只是类比：生成新图时，没有一张原图事先藏在噪声里等待复原；模型学习的是数据分布的规律。

2. 什么是噪声？

先用一个数字代替整张图。清晰样本是 2；我们抽到一个随机数字 −0.5，把它作为噪声。标准高斯噪声通常在 0 附近，正负数都可能出现，每次抽样一般不同。图片时每个像素都有噪声；动作序列时每个动作分量都有噪声。

为控制干净信号与噪声各占多少，引入 0 到 1 之间的累计信号系数 ᾱ（读作 alpha bar）。它越接近 1，样本保留的原始信息通常越多；越接近 0，噪声占比越大。当前加噪程度用扩散步 k 编号，和机器人真正执行动作的环境时间不是一回事。

查看可复制的 LaTeX 源码x_k=\sqrt{\bar{\alpha}_k}\,x_0+\sqrt{1-\bar{\alpha}_k}\,\epsilon

公式只是在把两份东西相加：第一项是缩放后的干净样本，第二项是缩放后的随机噪声。x₀ 是干净样本，xₖ 是加噪样本，ε 是实际抽到的噪声，ᾱₖ 是第 k 个噪声程度的累计系数；根号让两个系数的平方和为 1。

一维手算。假设 x₀=2，ᾱₖ=0.64，抽到 ε=−0.5。两项系数分别是 0.8 和 0.6，所以带噪值是 0.8 × 2 + 0.6 × (−0.5) = 1.3。换一个噪声，结果也会变。这里的 0.64 和 −0.5 都是人为设定的教学例子。
动手改变噪声比例

固定干净值为 2、此次噪声为 −0.5，调整累计信号系数。注意这只展示一次固定噪声，不表示平均效果。

3. 网络究竟学什么？

我们知道刚才自己加的噪声是 −0.5，于是把带噪样本 1.3 和噪声程度 k 交给网络，要求它预测那个噪声。如果预测 −0.3，误差是 0.2，平方误差是 0.04。训练中对许多样本、噪声程度和随机噪声求平均。

查看可复制的 LaTeX 源码L_{\mathrm{noise}}=\mathbb{E}\left[\left\|\epsilon-\epsilon_{\theta}(x_k,k,c)\right\|^2\right]

ε 是实际加进去的噪声，εθ 是网络预测的噪声；θ 表示网络参数。c 表示可选条件：例如希望机械臂参考当前观测生成动作。训练目标是缩小预测误差；这是常见的噪声预测版本，不是所有扩散模型都必须使用同一种预测目标。这里还有一个重要的限制：网络看到带噪值 1.3，并不能凭它唯一确定原来的干净值和噪声；不同组合可能得到同一个 1.3。训练提供很多样本，让网络学到在这个噪声水平与条件下怎样预测更合理，而不是保证每次准确找回当初那个噪声。

# clean [B,H,D]：一批干净动作序列；noise 与它形状相同
noise = torch.randn_like(clean)       # 我们自己抽的噪声，作为答案
abar = alpha_bars[k].view(B, 1, 1)   # 每个样本各自的噪声程度
noisy = abar.sqrt() * clean + (1 - abar).sqrt() * noise
prediction = model(noisy, k, condition)  # 预测噪声，形状 [B,H,D]
loss = ((prediction - noise) ** 2).mean()

上例中 B 是批大小，H 是动作序列长度，D 是每个动作的维度；view(B,1,1) 让每个样本的系数扩展到该样本所有时间步和动作维度。这里展示损失如何构造，模型、数据、时间步索引和优化器须由完整程序提供。

4. 训练随机挑一步，生成为什么要很多步？

训练时，我们已经有干净样本，并且可以用前面的公式直接制造“第 k 级”带噪样本；随机挑不同的 k 训练，长期就能覆盖不同噪声水平，不必每次从第一步一路加到第 k 步。

生成时没有干净样本给我们。我们从一份随机噪声开始：给网络当前噪声样本和噪声程度，预测其中噪声；采样器据此生成稍微干净一点的样本，再重复。许多步之后才得到生成结果。具体更新还取决于噪声日程、采样器和方差设置，不能理解成“每次直接减去网络预测的全部噪声”。

# 生成流程示意：model 与 sampler 为训练好和配置好的组件
x = initial_noise                         # [B,H,D]，一批随机动作块
for k in reversed(range(num_diffusion_steps)):
    predicted_noise = model(x, k, condition)  # 网络预测噪声
    x = sampler.step(predicted_noise, k, x)   # 按采样器规则计算下一步
# x 是生成结果；机器人动作执行前可能还需反归一化

这里的 sampler.step 是示意接口，具体参数取决于使用的库。循环的每一步都在计算同一个动作块；机器人此时还没有执行这个块。

训练：干净数据 + 自己加的噪声→ 预测噪声，算损失
生成：随机噪声→ 预测与采样→ 多次重复→ 生成数据
拓展：噪声日程中的 α 和 β

在常见 DDPM 设定里，每步有一个小的噪声强度 β，定义 α=1−β；累计系数 ᾱ 是从第一步到当前步所有 α 的乘积。训练时通过累计系数可直接从干净样本采样任意噪声级别。噪声日程是整串 β 的选择，它决定加噪过程与采样器所需的系数。

查看可复制的 LaTeX 源码\alpha_k=1-\beta_k,\qquad \bar{\alpha}_k=\prod_{i=1}^{k}\alpha_i

下标 i 是从第一步数到第 k 步的索引；乘积符号表示把这些 α 依次相乘。比如 α₁=0.9、α₂=0.8，则 ᾱ₂=0.72。

串起来：我们用干净数据自己构造带噪输入和答案；网络学着预测噪声；生成时从噪声开始，按照采样器多步逐渐生成样本。

练习：分清四个东西

① 上面的 2、1.3、−0.5 分别是什么？② 若网络预测 −0.3，单个数的平方误差是多少？③ 为什么生成时不能把 x₀ 当输入？

答案：① 依次是干净样本、加噪样本和实际抽到的噪声。② 0.04，因为预测与目标相差 0.2。③ 新生成时不存在对应的干净样本，要从随机噪声通过学到的反向过程生成。

第 07 讲 · 约 60–85 分钟
把扩散模型用在机器人动作上

1. 一道有两个答案的题

想象机械臂要去抓杯子，杯子前有障碍物。专家演示时可以从左绕，也可以从右绕；这两条路都合理。假设在几乎相同的观测下，左绕第一步的横向动作是 −1，右绕是 +1。

你在 W6 接触过把动作当作监督学习标签的行为克隆。如果一个确定性模型只输出一个动作，并用均方误差拟合这两个标签，它会倾向输出平均值 0。这个平均动作可能直冲障碍物。多个合理答案相互平均就是这里的困难。

但别扩大结论：并不是所有行为克隆都会平均；使用多峰分布的 BC 也能表示多个答案。这个例子只说明确定性单点回归在多解问题上的一个风险。

2. 把扩散模型的“图片”换成动作序列

我们让模型看到当前观测，例如物体位置或相机图像。训练数据是一段专家动作，先人为往动作中加噪声，再让网络根据观测和噪声程度预测噪声。训练好以后，给出当前观测，从随机噪声逐步生成一段可能的动作。

查看可复制的 LaTeX 源码p_{\theta}(A\mid O),\qquad A=[a_t,a_{t+1},\ldots,a_{t+H-1}]

这个式子表达“给定观测 O，动作序列 A 有哪些可能”。它不直接告诉你某条路是否安全，只描述模型学到的条件动作分布。不同随机初始噪声有可能产生不同的合理动作序列，但模型也可能生成失败动作，仍须做真实的闭环评估。

3. 一个动作块长什么样？

假设一个动作是 3 个坐标组成的向量，连续预测 8 步，那么一个动作块可以看作一张 8 行、3 列的表：每行一个环境动作，每列一个动作分量。若一次训练拿 32 个动作块，形状就是 [32, 8, 3]。

维度数字表示什么
第 1 维 B32本批有 32 个训练样本
第 2 维 H8每个样本预测 8 个未来环境动作
第 3 维 D3每个动作有 3 个数

这 3 维仅为教学例子。你仓库中的 FetchReach 环境接收四维动作，前 3 维是末端目标位移比例，第 4 维在该任务中无效；实际接入时要对齐环境接口，不可直接把示例三维数组送进去。

演示数据中，训练窗口要对齐观测与之后的动作，不能无意跨越两个回合。观测和动作量纲不同，通常用训练数据拟合归一化参数，推理时用同一组参数，输出动作后再反归一化。序列末尾不足长度时，要按具体实现的规则丢弃、填充或使用 mask。

4. 一次预测 8 步，就得闭眼执行 8 步吗？

不必。比如先生成 8 个未来动作，只执行前 2 个，然后重新看传感器，再生成新的 8 步。这叫滚动时域控制。H 表示预测多少步，E 表示每次执行多少步。

动作块时间轴（教学示意）

假设预测 H=8 步。滑动 E 看本轮执行哪些动作，绿色表示执行，灰色表示预测后暂不执行。

E 小：更频繁地重新观察，通常也需要更频繁运行模型；E 大：连续执行更久，推理次数可能更少，但应对意外变化的反馈更慢。具体好坏还取决于硬件、任务和推理延迟。

容易误会：“预测 8 步”与“去噪 8 次”是同一件事。
正确：8 个动作属于机器人时间轴；去噪次数属于生成器内部的计算步骤。模型可以去噪 100 次，最终生成包含 8 个动作的块。

5. 它和 PPO 什么关系？

问题普通回归 BCPPODiffusion Policy
数据从哪来专家示范策略与环境交互通常是专家示范
如何学习拟合专家动作根据奖励和优势改善策略根据观测学习动作序列的去噪生成
典型输出一个动作或动作块动作概率分布一段动作序列

扩散是生成数据的一种机制；Diffusion Policy 通常用示范进行模仿学习，并不因为名字里有 policy 就自动是 PPO 或 RL。

串起来：左绕右绕说明一个观测可能有多个好答案；扩散根据观测生成一个可能的动作块；执行一部分并重新观测，形成闭环。

练习：从数组走到机器人

① [32,8,3] 中 8 和 3 分别是什么意思？② H=8、E=2，执行两步之后怎么办？③ 多模态能力是否保证每次都绕过障碍？④ 去噪步数和动作块长度是同一个数吗？

答案：① 预测 8 个环境动作，每个动作 3 个分量。② 重新读取观测并预测下一块。③ 不能保证，需要闭环评估。④ 不是，它们是不同时间轴上的长度，可以不同。
