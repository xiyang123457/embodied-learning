**4. PD 控制（W4）**

单关节二阶模型，`I=0.1, b=0.5, q_d=1.0`。

`Kp` 三档（固定 `Kd=6.3`）：超调 0.00% / 0.00% / **12.84%**，上升 0.607 / 0.136 / 0.035 s。
`Kd` 三档（固定 `Kp=100`）：超调 **25.62%** / 0.00% / 0.00%，上升 0.061 / 0.136 / 0.466 s。

改 Kp 之后会突然开始超调，原因是 `ζ = (Kd+b)/(2√(Kp·I))`，**Kp 在分母上**。
所以「调 Kp 只影响快慢」是错的：Kp 一变 ζ 跟着变。反过来说，调参不用试：
想要 `ζ=1`、`Kp=100` 时，`Kd = 2√(Kp·I) − b = 5.82`。

> 这一条我按含粘性阻尼 `b` 的写法算的（`ζ = (Kd+b)/(2√(Kp·I))`）。
> 计划书 C3 写的是不含 `b` 的版本，用含 `b` 的 ζ 算出的理论超调和实测更接近
> （`Kp=400` 时 13.5% vs 实测 12.84%，不含 `b` 则是 16.5%）。

加了 `τ_g = −0.5` 的常值扰动后，稳态误差分别是 0.0207 / 0.0050 / 0.0012，
和 `|τ_g|/Kp` 逐个吻合。Kp 越大越小，但**永远不为 0** —— 到了稳态 `q̇=0`，
D 项不出力，P 项要出力就必须留误差。这就是需要积分项的直接理由。

顺带做了个方向自检：把 `Kd` 写成 `−2`，超调 2×10⁸%，指数发散。
不报错、不是 NaN、前几十毫秒看着还正常。这类错误只能靠「跑之前先想这个符号写反会怎样」防。
